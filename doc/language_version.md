# C-- 语言版本记录

## 版本号规则

**用简单整数：v1, v2, v3…… 不用 1.0.0 语义化版本。**

理由：语义化版本（major.minor.patch）的价值在于向**下游用户**传达兼容性
（"minor 升级不破坏 API"）。C-- 是教学语言，没有下游、没有兼容性承诺，
每个版本就是"语言又多会了一件事"。整数版本简单直白，和 plans.txt 的
P1/P2/P3/P4 阶段一一对应。哪天语言有了真实用户和 breaking change
的概念，再换语义化版本不迟。

## 当前版本：v4

## 版本历史

### v1（P1：最小骨架）
- `int main()` 单函数
- `return` 语句
- 算术运算：`+ - * /`、括号
- 整数字面量

### v2（P2：变量与语句块）
- 变量声明 `int a = 1;`（无初值自动初始化为 0）
- 赋值表达式 `a = b = 1;`（赋值是表达式，值为所赋的值）
- 嵌套语句块 `{ }` 与作用域遮蔽（内层同名变量遮蔽外层）
- 同作用域重定义报错
- 表达式语句

### v3（P3：控制流）
- 比较运算：`< > <= >= == !=`（结果为 0/1）
- `if` / `if-else`
- `while` 循环（支持嵌套）
- 一元负号 `-x`
- 取模 `%`

### v4（P4：函数）
- 多函数定义，均为 `int` 返回
- 函数参数（`int` 类型，RV32IM 约定 a0-a7 传递）
- 函数调用（含递归、相互递归）
- 函数可先使用后定义（编译器两遍扫描，无需前置声明）
- 函数体末无 return 时自动 `return 0`

## 已知边界（尚未支持）

- 参数个数超过 8 个（走栈传参未实现）
- `if (x) int a = 1;` 不带花括号的声明会泄漏进外层作用域（C 中非法）
- `for`、`break`/`continue`、`&&`/`||`/`!`、数组、指针、float、
  `void` 函数、全局变量
- 无函数级类型检查（实参类型 vs 形参类型）

## 词法约定

- 注释：`//` 行注释、`/* */` 块注释
- 标识符：字母/下划线开头，接字母数字下划线
- 关键字：`int return if else while`
