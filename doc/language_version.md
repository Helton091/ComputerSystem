# C-- 语言手册

C-- 是一门面向教学的类 C 语言，目标平台为 RISC-V RV32IMF。本文档既是版本记录，也是用户编程入门指南。

## 版本号规则

C-- 使用简单整数版本：v1、v2、v3…… 每个版本代表语言新增了一项主要能力，与开发阶段 P1/P2/P3…… 一一对应。

## 当前版本：v10（已完成）

---

## 1. 快速开始

一个最小的 C-- 程序：

```c
int main() {
    return 42;
}
```

程序从 `main` 函数开始执行，`main` 的返回值就是整个程序的退出状态（通过寄存器 `a0` 输出）。

### 1.1 程序结构

C-- 源文件由**顶层声明**组成，目前顶层只允许：

- 全局变量声明：`int g;` 或 `int g = 1;`
- 函数定义：`int foo(int x) { ... }` 或 `void bar() { ... }`

顶层不允许独立的表达式语句，例如 `a = b + 1;` 不能出现在函数外部。

全局变量在**整个源文件内互相可见**：函数可以访问在其之前或之后定义的全局变量，不需要前置声明。局部变量可以遮蔽同名的全局变量。

### 1.2 类型

C-- 目前支持的基础类型与派生类型：

| 类型 | 大小 | 说明 |
|------|------|------|
| `int` | 4 字节 | 有符号 32 位整数 |
| `float` | 4 字节 | IEEE 754 单精度浮点数 |
| `T*` | 4 字节 | 指向 `T` 的指针，`T` 可以是 `int`、`float`、`void` 或其他指针类型 |
| `T[n]` | 4×n 字节 | n 个连续存放的 `T` 元素，目前仅支持局部变量声明 |
| `void` | — | 只能作为函数返回类型或 `void*` 的基类型，不能声明普通变量 |

**注意：**
- `int` 与 `float` 之间不支持隐式类型转换。赋值、传参、返回都必须类型完全一致。
- 指针类型同样严格：`int*` 不能赋值给 `float*`，也不能用普通整数初始化指针（只能用 `nullptr` 或同类型地址）。
- `void*` 可以接收任意指针类型的赋值，但 `void*` 不能被解引用。

### 1.3 变量与作用域

变量必须先声明后使用：

```c
int main() {
    int a = 1;
    int b;
    b = a + 2;
    return b;
}
```

- 无初值的局部变量自动初始化为 0（`int`）或 0.0（`float`）。
- 支持嵌套语句块 `{ }`，内层变量可以遮蔽外层同名变量。
- 同一作用域内不允许重复声明同名变量。
- 全局变量无初值时默认初始化为 0 或 0.0。
- 全局变量初始化表达式必须是常量字面量，不能引用其他变量。例如 `int g = 1 + 2;` 合法，`int g = a + 1;` 非法。

全局变量示例：

```c
int count = 0;

void inc() {
    count = count + 1;
}

int main() {
    inc();
    return count;
}
```

### 1.4 表达式

支持的运算符（按优先级从高到低）：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 20 | `* / %` | 乘、除、取模（`%` 仅对 `int` 有效） |
| 10 | `+ -` | 加、减 |
| 5 | `< <= > >=` | 比较 |
| 4 | `== !=` | 等于、不等于 |
| 1 | `=` | 赋值，右结合 |
| 1 | `+= -= *= /= %=` | 复合赋值，右结合，优先级与 `=` 相同 |

比较和逻辑相等运算符返回 `int` 类型的 0 或 1，可用于 `if` / `while` 条件。

复合赋值要求左操作数必须是可修改的左值（变量、下标表达式、解引用表达式），右操作数类型必须与左操作数类型一致。复合赋值是表达式，其值为赋入左操作数的新值，因此可以链式使用，如 `a = b += 2;`。`%=` 仅对 `int` 类型有效。

一元负号 `-x` 对 `int` 和 `float` 都有效。

### 1.5 语句

```c
int main() {
    int x = 10;
    if (x > 5) {
        x = x - 1;
    } else {
        x = x + 1;
    }
    while (x > 0) {
        x = x - 1;
    }
    return x;
}
```

- `if` / `if-else`：条件必须是 `int` 类型。
- `while`：条件必须是 `int` 类型。
- `for`（v10 新增）：完整形式 `for (init; cond; update) body`。init 可以是一条变量声明（`int i = 0;`）或一个表达式语句，也可以留空；cond 留空视为恒真；update 可留空。`for` 语句自身构成一个作用域，init 中声明的变量在 cond、update、body 内可见，循环结束后消亡。条件与 `while` 一样必须是 `int` 类型。
- `break` / `continue`（v10 新增）：`break` 跳出最近一层循环，`continue` 跳过本轮剩余语句。在 `for` 中 `continue` 先执行 update 再判断 cond；在 `while` 中直接回到 cond。二者只能出现在循环体内，否则编译报错。`break`/`continue` 之后的语句属于不可达代码，合法但永不执行。
- `return`：返回值的类型必须与函数声明的返回类型一致；`void` 函数使用 `return;`，不得返回值。
- 表达式语句：例如 `foo();` 或 `a = 1;`。

### 1.6 函数

```c
int add(int a, int b) {
    return a + b;
}

int main() {
    return add(2, 3);
}
```

- 函数可以先使用后定义，无需前置声明。
- 参数和返回值类型必须匹配。
- 支持 `void` 返回类型：`void` 函数不返回值，调用时只能作为表达式语句使用。
- 函数体末尾没有 `return` 时，自动 `return 0`（对 `int` 函数）或 `return 0.0`（对 `float` 函数）；`void` 函数自动执行无值返回。

### 1.7 float 类型（v5 新增）

```c
float area(float r) {
    return 3.14 * r * r;
}

int main() {
    float x = 2.5;
    float y = area(x);
    if (y > 10.0) {
        return 1;
    }
    return 0;
}
```

- `float` 字面量形如 `3.14`、`2.5`、`0.0`。
- `float` 支持 `+ - * /` 和比较运算，不支持 `%`。
- `float` 参数通过 `fa0-fa7` 传递，返回值通过 `fa0`。
- 比较 `float` 表达式返回 `int` 结果。

### 1.8 指针（v8 新增）

```c
int main() {
    int a;
    int *p;
    p = &a;          // 取地址
    *p = 42;         // 解引用并赋值
    return a;        // 返回 42
}
```

支持的特性：

- 指针声明：`int *p;`、`float *pf;`、`void *vp;`、`int **pp;`（多级指针）。
- 取地址：`&x` 返回变量 `x` 的地址，类型为 `T*`。
- 解引用：`*p` 访问指针 `p` 指向的对象。
- 指针赋值：`p = &a;`、`pp = &p;`、`p = nullptr;`。
- 指针传参与返回：函数可以接受 `T*` 参数并返回 `T*`。
- `nullptr`：表示任意类型的空指针，是唯一能直接给指针赋的常量。

限制：

- 不支持指针算术（如 `p + 1`、`p - p`）。
- 不支持函数指针。
- 全局指针变量只能用 `nullptr` 初始化。
- 无显式初始化的局部指针变量自动初始化为 `nullptr`。

### 1.9 数组（v9 新增）

```c
int main() {
    int a[3];
    a[0] = 10;
    a[1] = 20;
    a[2] = a[0] + a[1];
    int sum = 0;
    int i = 0;
    while (i < 3) {
        sum = sum + a[i];
        i = i + 1;
    }
    return sum;
}
```

- 数组声明 `T name[n];`：长度 `n` 必须是**编译期可求值的正整数常量**，不能省略，也不能是变量。
- 下标访问 `a[i]`：下标表达式必须是 `int` 类型。`a[i]` 是左值，可以读、可以赋值，也可以取地址（`&a[i]` 得到 `T*`）。
- **数组元素的初始内容是未定义行为**：声明数组不会清零内存，读取未赋值过的元素结果不可预测，使用前必须先写入。
- 编译器不做下标越界检查，越界访问是未定义行为（可能破坏栈帧）。

限制：

- 只支持一维数组，不支持 `int a[2][3]`。
- 数组只能声明为局部变量，全局数组暂不支持。
- 不支持初始化列表：`int a[3] = {1, 2, 3};` 非法。
- 数组不会退化为指针，也不能整体赋值：数组之间的 `a = b` 非法；数组名本身不能作为值使用（如 `return a;`）。
- 函数参数类型与返回类型不能是数组。

### 1.10 词法约定

- 注释：`//` 行注释，`/* */` 块注释。
- 标识符：字母或下划线开头，后接字母、数字、下划线。
- 关键字：`int`、`float`、`void`、`return`、`if`、`else`、`while`、`for`、`break`、`continue`、`nullptr`。

## 2. 版本历史

### v1（P1：最小骨架）
- `int main()` 单函数
- `return` 语句
- 算术运算：`+ - * /`、括号
- 整数字面量

### v2（P2：变量与语句块）
- 变量声明 `int a = 1;`（无初值自动初始化为 0）
- 赋值表达式 `a = b = 1;`（赋值是表达式，值为所赋的值）
- 嵌套语句块 `{ }` 与作用域遮蔽（内层同名变量遮蔽外层）
- 同作用域重定义报错
- 表达式语句

### v3（P3：控制流）
- 比较运算：`< > <= >= == !=`（结果为 0/1）
- `if` / `if-else`
- `while` 循环（支持嵌套）
- 一元负号 `-x`
- 取模 `%`

### v4（P4：函数）
- 多函数定义
- 函数参数（`int` 类型，RV32IM 约定 a0-a7 传递）
- 函数调用（含递归、相互递归）
- 函数可先使用后定义（编译器两遍扫描，无需前置声明）
- 函数体末无 return 时自动 `return 0`

### v5（P5：float 变量与函数）
- 新增 `float` 基础类型
- `float` 字面量与变量声明
- `float` 算术运算：`+ - * /`、一元负号
- `float` 比较运算：`< > <= >= == !=`
- `float` 函数参数与返回值（RV32F 约定 fa0-fa7 传递）
- 严格的 `int`/`float` 类型检查，禁止隐式转换
- 浮点结果可通过模拟器 trace 输出 `fa0`，或调用自定义 syscall `a7=2` 打印

### v6（P6：全局变量）
- 顶层支持全局变量声明：`int g;`、`float pi = 3.14;`
- 全局变量全文件可见，函数无论定义顺序均可访问
- 局部变量可遮蔽全局变量
- 全局变量初始化表达式仅限常量字面量，禁止引用其他变量
- 未显式初始化的全局变量默认值为 0 或 0.0

### v7（P7：`void` 函数）
- 新增 `void` 返回类型
- `void` 函数使用 `return;`，不允许返回具体值
- `void` 函数调用只能作为表达式语句出现，不能参与赋值、运算等值上下文
- 非 `void` 函数不允许写空的 `return;`
- 禁止 `void` 作为变量类型或参数类型

### v8（P8：最小指针子集）
- 新增指针类型 `T*` 与 `void*`
- 支持取地址 `&x`、解引用 `*p`、指针赋值与传参返回
- 新增 `nullptr` 关键字，作为唯一的指针常量
- 严格的指针类型检查，禁止 `int`/`float` 与指针之间的隐式转换
- 局部指针变量默认初始化为 `nullptr`，全局指针变量只能用 `nullptr` 初始化

### v9（P9：一维数组）
- 新增数组类型 `T[n]` 与下标表达式 `a[i]`
- 数组元素寻址编译为 GETPTR 指令（基地址 + 下标 × 元素大小），支持 `int`/`float` 元素
- `a[i]` 是左值，支持读取、赋值与取地址 `&a[i]`（得到 `T*`）
- 长度必须是编译期正整数常量，下标必须是 `int` 表达式
- 严格限制：仅局部一维数组，无初始化列表、无整体赋值、无数组-指针退化
- 数组元素初始内容为未定义行为（声明不清零内存）

### v10（P10：循环控制与复合赋值）
- `for` 循环：`for (init; cond; update) body`，三个子句均可留空
- init 支持声明语句或表达式语句；for 自身构成新作用域，init 声明的变量在循环后消亡
- cond 留空视为恒真；脱糖为 init + while + update 块，IR 层无新指令
- 复合赋值：`+= -= *= /= %=`，左值只求值一次，支持 `int` 与 `float`，`%=` 仅对 `int`
- `break` / `continue`：break 跳转至循环 end 块，continue 在 `for` 中跳转至 update 块、在 `while` 中跳转至 cond 块；只作用于最内层循环
- break/continue 之后的语句进入不可达代码块，合法但永不执行；循环外使用为编译错误

## 3. 已知边界（尚未支持）

- 参数个数超过 8 个（走栈传参未实现）。
- `if (x) int a = 1;` 不带花括号的声明会泄漏进外层作用域（C 中非法）。
- 逻辑运算符 `&&`/`||`/`!`。
- 自增自减 `++`/`--`（未实现）。
- 多维数组、数组初始化列表、全局数组、数组整体赋值与数组-指针退化。
- `int` 与 `float` 之间不支持任何类型转换（包括显式强制类型转换）。
