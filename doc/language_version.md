# C-- 语言手册

C-- 是一门面向教学的类 C 语言，目标平台为 RISC-V RV32IMF。本文档既是版本记录，也是用户编程入门指南。

## 版本号规则

C-- 使用简单整数版本：v1、v2、v3…… 每个版本代表语言新增了一项主要能力，与开发阶段 P1/P2/P3…… 一一对应。

## 当前版本：v5

---

## 1. 快速开始

一个最小的 C-- 程序：

```c
int main() {
    return 42;
}
```

程序从 `main` 函数开始执行，`main` 的返回值就是整个程序的退出状态（通过寄存器 `a0` 输出）。

### 1.1 程序结构

C-- 源文件由**顶层声明**组成，目前顶层只允许：

- 全局变量声明：`int g;` 或 `int g = 1;`
- 函数定义：`int foo(int x) { ... }`

顶层不允许独立的表达式语句，例如 `a = b + 1;` 不能出现在函数外部。

### 1.2 类型

C-- 目前支持两种基础类型：

| 类型 | 大小 | 说明 |
|------|------|------|
| `int` | 4 字节 | 有符号 32 位整数 |
| `float` | 4 字节 | IEEE 754 单精度浮点数 |

**注意：** `int` 与 `float` 之间不支持隐式类型转换。赋值、传参、返回都必须类型完全一致。

### 1.3 变量与作用域

变量必须先声明后使用：

```c
int main() {
    int a = 1;
    int b;
    b = a + 2;
    return b;
}
```

- 无初值的局部变量自动初始化为 0（`int`）或 0.0（`float`）。
- 支持嵌套语句块 `{ }`，内层变量可以遮蔽外层同名变量。
- 同一作用域内不允许重复声明同名变量。

### 1.4 表达式

支持的运算符（按优先级从高到低）：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 20 | `* / %` | 乘、除、取模（`%` 仅对 `int` 有效） |
| 10 | `+ -` | 加、减 |
| 5 | `< <= > >=` | 比较 |
| 4 | `== !=` | 等于、不等于 |
| 1 | `=` | 赋值，右结合 |

比较和逻辑相等运算符返回 `int` 类型的 0 或 1，可用于 `if` / `while` 条件。

一元负号 `-x` 对 `int` 和 `float` 都有效。

### 1.5 语句

```c
int main() {
    int x = 10;
    if (x > 5) {
        x = x - 1;
    } else {
        x = x + 1;
    }
    while (x > 0) {
        x = x - 1;
    }
    return x;
}
```

- `if` / `if-else`：条件必须是 `int` 类型。
- `while`：条件必须是 `int` 类型。
- `return`：返回值的类型必须与函数声明的返回类型一致。
- 表达式语句：例如 `foo();` 或 `a = 1;`。

### 1.6 函数

```c
int add(int a, int b) {
    return a + b;
}

int main() {
    return add(2, 3);
}
```

- 函数可以先使用后定义，无需前置声明。
- 参数和返回值类型必须匹配。
- 函数体末尾没有 `return` 时，自动 `return 0`（对 `int` 函数）或 `return 0.0`（对 `float` 函数）。

### 1.7 float 类型（v5 新增）

```c
float area(float r) {
    return 3.14 * r * r;
}

int main() {
    float x = 2.5;
    float y = area(x);
    if (y > 10.0) {
        return 1;
    }
    return 0;
}
```

- `float` 字面量形如 `3.14`、`2.5`、`0.0`。
- `float` 支持 `+ - * /` 和比较运算，不支持 `%`。
- `float` 参数通过 `fa0-fa7` 传递，返回值通过 `fa0`。
- 比较 `float` 表达式返回 `int` 结果。

### 1.8 词法约定

- 注释：`//` 行注释，`/* */` 块注释。
- 标识符：字母或下划线开头，后接字母、数字、下划线。
- 关键字：`int`、`float`、`return`、`if`、`else`、`while`。

## 2. 版本历史

### v1（P1：最小骨架）
- `int main()` 单函数
- `return` 语句
- 算术运算：`+ - * /`、括号
- 整数字面量

### v2（P2：变量与语句块）
- 变量声明 `int a = 1;`（无初值自动初始化为 0）
- 赋值表达式 `a = b = 1;`（赋值是表达式，值为所赋的值）
- 嵌套语句块 `{ }` 与作用域遮蔽（内层同名变量遮蔽外层）
- 同作用域重定义报错
- 表达式语句

### v3（P3：控制流）
- 比较运算：`< > <= >= == !=`（结果为 0/1）
- `if` / `if-else`
- `while` 循环（支持嵌套）
- 一元负号 `-x`
- 取模 `%`

### v4（P4：函数）
- 多函数定义
- 函数参数（`int` 类型，RV32IM 约定 a0-a7 传递）
- 函数调用（含递归、相互递归）
- 函数可先使用后定义（编译器两遍扫描，无需前置声明）
- 函数体末无 return 时自动 `return 0`

### v5（P5：float 变量与函数）
- 新增 `float` 基础类型
- `float` 字面量与变量声明
- `float` 算术运算：`+ - * /`、一元负号
- `float` 比较运算：`< > <= >= == !=`
- `float` 函数参数与返回值（RV32F 约定 fa0-fa7 传递）
- 严格的 `int`/`float` 类型检查，禁止隐式转换
- 浮点结果可通过模拟器 trace 输出 `fa0`，或调用自定义 syscall `a7=2` 打印

---

## 3. 已知边界（尚未支持）

- 参数个数超过 8 个（走栈传参未实现）。
- `if (x) int a = 1;` 不带花括号的声明会泄漏进外层作用域（C 中非法）。
- `for`、`break`/`continue`、`&&`/`||`/`!`、数组、指针、`void` 函数。
- 函数级类型检查已覆盖 `int`/`float`，但报错信息还可进一步完善。

## 4. 开发中特性

### v6 计划：全局变量（等待实现）

计划新增全局变量支持，初步设计如下：

- 顶层允许全局变量声明，例如：

  ```c
  int g;
  float pi = 3.14;
  ```

- 全局变量在**整个源文件内互相可见**，函数无论定义顺序均可访问。
- 局部变量遮蔽全局变量。
- 全局变量初始化表达式**只能使用常量**，不允许引用其他变量（包括全局变量）。例如：

  ```c
  int a = 1 + 2;       // OK
  float f = 2.5;       // OK
  int b = a + 1;       // ERROR：不能引用其他变量
  ```

- 未显式初始化的全局变量默认值为 0 或 0.0。
- 顶层不允许独立的表达式语句或控制流语句。

该设计旨在避免全局变量初始化顺序问题，保持语义简单明确。
